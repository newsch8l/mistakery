## Техническое устройство (разобрано 17.07)

- `scripts/build-pages.cjs`: копирует игру в `dist/`, генерирует `cards.bundle.js` из cards.json, строит `dist/map/index.html` из `visualization/mistakery-map.template.html`: достаёт документ из `srcdoc="..."` iframe (HTML-энтити декодируются), **вживляет текущий deck и translations** регексами (`var deck={...}` / `var translations={...}`), патчит категории и счётчики регексами (`{id:'agents'...note:'9'}` и т.п.).
- Категории карт в сборке и в шаблоне: opening / agents / padel / packageA / b3 / pressure. SADBOT-карты (kind story, без `arc`) упадут в 'other' — категорию надо добавить в обоих местах.
- Структурная схема в шаблоне — **рукописная**: массивы узлов/окон/пояснений с конкретными ID карт (`insertionWindows`, `memoryReaders`, `convergence`, `protectedPairs`, `allNodes` и пр., смотреть регион ~98K–118K символов внутри srcdoc-документа). Это не рендер из данных — это авторская проза. Для v2 переписывается руками.
- `scripts/sync-translations.cjs`: контракт описан в шаге 3.
- В шаблоне подключены CDN-скрипты (floating-ui, lucide) — работают только онлайн, при локальной проверке не пугаться деградации тултипов.
