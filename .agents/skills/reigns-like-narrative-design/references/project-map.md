# Mistakery project map

The project root contains `cards.json`, `game.js`, `README.md` and `MISTAKERY_START_HERE.md`.

Read the entrypoint before using this skill. Load these files selectively:

- `docs/core/STATE_BIBLE.md`: world facts, commercial funnel and resource meaning.
- `docs/core/TOV_BIBLE.md`: voice, readability and messenger rules.
- `docs/core/REJECTED_PATTERNS.md`: rejected copy and structural traps.
- `docs/design/REIGNS_RUBRIC.md`: pass/warning/fail criteria.
- `docs/research/REIGNS_RESEARCH.md`: source-backed rationale and adaptation notes.

Current test scope is defined by `MISTAKERY_START_HERE.md`, `cards.json`, `game.js` and tests. An intentionally isolated onboarding test does not define the future full-run architecture. Run the analyzer before claiming a structural fact.
